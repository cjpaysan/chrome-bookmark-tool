# 书签检测 / 整理 / 同步账号删除工具

> 🍎 **macOS 专用**（Apple Silicon / Intel 均可）· 本地桌面应用 · 数据完全本地

读取 Chrome / Edge 等 Chromium 系浏览器的书签 → 检测链接有效性 → 查重 → 整理 →
安全删除**同步账号**里"删不掉"的重复书签。

## 一个关键事实（为什么需要装一个常驻扩展）

同步账号的书签存于 `AccountBookmarks`，云端是权威；直接改本地文件会被云端覆盖回滚，
导致删掉的书签"复活"。唯一正解是用 Chrome 官方 `chrome.bookmarks` 接口在同步开启时删除
（删除会成为"墓碑"同步上云，不再复活）——而该接口只有**扩展**能调用。

稳定版 Chrome 137+ 已禁用命令行加载扩展，无法静默把扩展塞进你正在用的 Chrome；
因此采用最简单可靠的方案：**你在 Chrome 里一次性「加载已解压的扩展程序」装入随附扩展，
装一次、永久生效**。扩展常驻并只听本机 `127.0.0.1` 的删除指令，删完后**不自卸载、不退出登录、不重启浏览器**。

> 装之前工具会先弹窗说明原因（为什么不能直接删文件、为什么必须装扩展、扩展是否安全），确认后再给安装指引。

## 使用方法

- macOS：双击 `start.command`（首次需在弹窗里允许运行）
- Windows：双击 `start.bat`
- 浏览器打开 `http://localhost:4789`

操作步骤：
1. 在"书签来源"选择你的浏览器 / 配置文件（同步账号会标注"同步账号"）。
2. 点"开始扫描"。
3. 在"重复 / 冗余书签"里勾选要处理的书签，点"删除选中"。
4. 若来源是同步账号：
   - 第一次会先弹窗说明"为什么必须装扩展"，点"我明白了，去安装"。
   - 按指引下载扩展包 → 解压到自有文件夹 → 去隔离 → `chrome://extensions` 开开发者模式 → 加载已解压的扩展程序 → 选该文件夹。
   - 装好后右上角"随附扩展"徽标变绿，再点"删除选中"即一键自动删除。
   - 之后每次删除同步书签都全自动，**无需再装**。
   - 不想装扩展时，也可选"改用清单手动删"，导出带复选框的 HTML 清单在书签管理器里逐条删。

## 隐私

随附扩展仅与本机 `localhost` 通信，不做任何网络上报、不上传你的书签；删除只调用本地 Chrome 官方接口。
可随时在 `chrome://extensions` 一键关闭或移除。

## 目录说明

- `src/server.js` — 本地 Web 服务（GUI + 扫描 + 文件夹选择 + 常驻扩展桥接）
- `public/` — 前端页面
- `ext/` — 常驻扩展源码（manifest.json + background.js），由 `make-ext-zip.mjs` 打包为 `ext/bookmark-cleaner-extension.zip`
